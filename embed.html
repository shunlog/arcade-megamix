iframe embed demo

The box below is an <iframe> whose src points at the game's own page (./index.html). The game runs in its own browsing context, completely isolated from this document.

How it works:
  • src is the only thing needed to embed a page — no bundler or build step.
  • The embedded game opens on its own startup menu; pick a mode there.
  • Keyboard focus lives inside the iframe, so click the game once before playing.
  • allow="fullscreen" lets the embedded page request fullscreen.
  • Same-origin here, so this page can reach into iframe.contentWindow if it ever needs to.
